1. INTRO                                                *neon-wave-intro*

Neon Wave is a Neovim colorscheme generated from the palettes of
100-themes (https://github.com/bjarneo/100-themes). It ships five variants:
dark, day, high contrast, day high contrast and oled.

==============================================================================
2. COLORSCHEMES                                  *neon-wave-colorschemes*

                                                        *neon-wave-colorscheme*
Apply a variant with: >

  :colorscheme neon-wave

Available names:

  neon-wave                       dark
  neon-wave-day                   light
  neon-wave-high-contrast         dark, WCAG AAA
  neon-wave-day-high-contrast     light, WCAG AAA
  neon-wave-oled                  dark on pure black

==============================================================================
3. SETUP                                                *neon-wave-setup*

  require('neon-wave').setup({
    transparent = false,
    dim_inactive = false,
    styles = {},
    on_highlights = nil,
    integrations = {},
    palette_overrides = {},
    terminal = true,
  })

  Then: >

  vim.cmd.colorscheme('neon-wave')

==============================================================================
4. OPTIONS                                              *neon-wave-options*

  transparent           boolean   make editor backgrounds transparent
  dim_inactive          boolean   dim inactive windows
  styles                table     per-group bold/italic/underline overrides
  on_highlights         function  hook(hl, palette) before applying
  integrations          table     enable/disable a plugin's groups
  palette_overrides     table     per-colorscheme color overrides
  terminal              boolean   set |g:terminal_color_0| .. |g:terminal_color_15|
